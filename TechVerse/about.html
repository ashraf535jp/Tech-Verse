About TechVerse

Discover the purpose behind this university web programming project.

Project Overview

TechVerse is a responsive technology news website created as a Web Programming assignment using HTML, CSS, and JavaScript.

The website provides a modern interface for browsing technology news across multiple categories including Artificial Intelligence, Gaming, Cybersecurity, Space, and Mobile Technology.

Project Goals

  • Responsive web design
  • Clean user interface
  • Multi-page navigation
  • Modern CSS styling
  • Interactive JavaScript features
  • GitHub Pages compatibility
